# Earn Bot Mini App

## 📂 الملفات
- index.html → واجهة التطبيق
- ads.js → تشغيل الإعلانات
- wheel.js → عجلة الحظ
- users.json → تخزين بيانات المستخدمين
- dashboard.js → لوحة تحكم
- bot.js → كود البوت

## 🚀 التشغيل
1. ارفع الملفات على GitHub.
2. فعل GitHub Pages من Settings → Pages → Branch: main.
3. انسخ الرابط الناتج وأضفه في كود البوت (bot.js).
4. شغل البوت على justrunmy.app أو أي استضافة Node.js.
